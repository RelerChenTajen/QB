# exam-to-qb — 題目檔案轉題庫 CSV

把使用者提供的題目文件抽取成結構化題目，套用題庫範本（27 欄）輸出成可匯入的 CSV。

## 何時使用
- 使用者提供一份含考題的檔案（Word/PDF/純文字/Markdown）並要求轉成題庫格式或某個 `exam*.csv`。
- 需沿用本專案題庫範本（題型、答案、解說、難易度、選項 1~20 欄位）。

## 重要約定
- **編碼一律 UTF-8 (no BOM)**（本專案慣例，見記憶 [[qb-csv-encoding]]）。最終輸出與所有中繼檔都用 no BOM。
- 腳本本身一律只寫 ASCII，中文只放在 **TSV 中繼檔**與 `header.csv`（皆以 UTF-8 讀取），避免腳本檔自身的編碼問題。
- 寫入含 `\n` token 的檔案時避免經過 shell heredoc：反斜線可能被吞掉，導致 token 失效。用檔案寫入工具直接產生。

## 題庫格式（27 欄）速查
| 欄 | 名稱 | 說明 |
|----|------|------|
| 1 | 題組 | 留空（題庫不支援） |
| 2 | 類別 | 可選；匯入線上測驗時不支援，僅題庫內分類 |
| 3 | 題型 | 1=是非 2=單選 3=複選 4=填充 5=問答 |
| 4 | 題目 | 題幹；**填充題**把答案內嵌成 `[*答案*]` |
| 5 | 答案 | 是非:1=是/2=否；單選:選項編號；複選:`1,2,4`；填充:留空；問答:參考答案 |
| 6 | 解說 | 可空 |
| 7 | 難易度 | 1=容易 2=適中 3=困難 |
| 8 | 選項1 | 選擇題=選項文字；**填充題**=1不分大小寫/2區分大小寫 |
| 9 | 選項2 | 選擇題=選項文字；**填充題**=1不考慮順序/2需考慮順序 |
| 10–27 | 選項3–20 | 其餘選項 |

## 流程

### 1. 取得題目文字
- **.docx**：它是 zip。解壓後讀 `word/document.xml`，逐 `w:p` 段落串接 `w:t` 取得純文字（見下方範例指令）。
- **.pdf**：用 Read 工具直接讀（支援 PDF）。
- **.txt/.md/.csv**：直接 Read。
- **.doc（舊版二進位）**：嘗試另存或請使用者轉成 .docx；無法解析時告知使用者。

docx／txt／md 取文字（跨平台，於 skill 目錄執行）：
```bash
python extract.py <來源檔> -o <輸出.txt>
```
輸出省略 `-o` 時直接印到 stdout。`.pdf` 請用宿主 agent 自己的 PDF 讀取能力，`.doc` 請使用者另存 `.docx`。

### 2. 解析成題目
逐題判斷題型，整理出：題型 / 題目 / 答案 / 解說 / 難易度 / 各選項。常見來源寫法的對應：
- 「答案：❌錯誤 / ✅正確」→ 是非，2 / 1。
- 「答案：(B)」→ 單選，選項編號（A=1,B=2,…）。**移除選項前綴 (A)(B)**，只留文字。
- 「答案：(A)(B)(D)」→ 複選，`1,2,4`。
- 填充題「______」「【 1 】」→ 把對應答案內嵌成題目中的 `[*答案*]`；單格一個、多格多個。
- 問答題 → 參考答案放第 5 欄；多行用 `\n` 標記（見下）。
- **難易度**若來源未標示，依配分或題型推估，並在回報時說明此為推估、可調整。

### 3. 寫 TSV 中繼檔
每題一行，欄位以 **TAB** 分隔，順序：
`題型 ⇥ 題目 ⇥ 答案 ⇥ 解說 ⇥ 難易度 ⇥ 選項1 ⇥ 選項2 ⇥ 選項3 ⇥ …`
- 任何欄位內的換行用兩字元 token `\n`（反斜線＋n）表示，引擎會轉成 CRLF 並自動加引號。
- 填充題：答案欄留空、選項1/選項2 放 1/2 旗標。
- 用檔案寫入工具產生 TSV（UTF-8）。

### 4. 提示使用者是否填入類別（必做）
產生前詢問：**是否要填入「類別」欄？** 若要，請使用者提供類別名稱（例如「綠色能源」）。
- 注意提醒：類別欄在「匯入線上測驗時不支援」，僅供題庫內分類。
- 使用者若已在指令中指明類別，直接採用，不必再問。
- **來源分多個章節時**（例如 1-1／1-2／1-3），改用「每列一個類別」的 `.cats` 檔：一行對應 TSV 的一列，行數必須與題數相同。

### 5. 執行轉換引擎
```bash
# 全部同一個類別
python build.py --tsv <rows.tsv> --out <examNN.csv> --category "<類別>" --big5

# 各題依章節填不同類別
python build.py --tsv <rows.tsv> --out <examNN.csv> --category-file <rows.cats> --big5
```
- 在 skill 目錄下執行；`--header` 可選，預設用同目錄的 `header.csv`。
- `--category` 與 `--category-file` 互斥；`.cats` 行數與 TSV 列數不符會直接報錯，不會產生半套輸出。

**Big5 副本**：加 `--big5` 會同時輸出 `examNN_big5.csv`（cp950，給只吃 Big5 的舊測驗系統）。
- 命名規則：在副檔名前插入 `_big5`（`exam02.csv` → `exam02_big5.csv`）。可用 `--big5-out <路徑>` 自訂。
- Big5 字集較小：引擎會把 `≥`→`≧`、`≤`→`≦`、`・`→`‧` 做等義替換；若仍有無法表示的字元，會以 `?` 寫入並印出 `WARN ... UNMAPPABLE`，需回報使用者並考慮改寫該字。
- 預設是否要 Big5 副本，可在步驟 4 一併詢問使用者（很多線上系統其實吃 UTF-8，不一定需要）。

### 6. 驗證並回報
- 開啟輸出確認中文正常、欄位對齊、複選答案有引號、填充 `[*..*]` 正確。
- 確認引擎輸出的 `BOM=False`。
- 回報：題數、各題型分佈、難易度是否為推估、類別是否已填、檔案路徑。

## 檔案
- `build.py` — **轉換引擎（主要）**；跨平台，Python 3.7+。
- `extract.py` — docx／txt／md 取文字；跨平台，Python 3.7+。
- `build.ps1` — 舊版 Windows PowerShell 引擎，保留供既有流程相容；新流程一律用 `build.py`（不支援 `--category-file`）。
- `header.csv` — 題庫範本 27 欄表頭（version 行 + 標題列）。
- `examples/` — 可放範例。
